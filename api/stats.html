Statistics & Metrics¶

Statistical metrics for semiconductor process analysis.

fabplot.stats.metrics.calculate_metrics(data: ndarray, lsl: float | None = None, usl: float | None = None) → dict[str, float][source]¶

Calculate statistical indicators N, Mean, Sigma, and Cpk.

Parameters:

  • data (numpy.ndarray) – 1D numpy array of numerical data.

  • lsl (float or None) – Lower Specification Limit (optional).

  • usl (float or None) – Upper Specification Limit (optional).

Returns:

Dictionary with keys n, mean, sigma, and optionally cpk.

Return type:

dict[str, float]

fabplot.stats.metrics.calculate_ratio(y1: ndarray, y2: ndarray) → ndarray[source]¶

Calculate element-wise ratio y1 / y2 for the compare panel.

Zero or NaN denominators produce NaN entries without raising a ZeroDivisionError.

Parameters:

  • y1 (numpy.ndarray) – Numerator array (e.g. measured data).

  • y2 (numpy.ndarray) – Denominator array (e.g. simulation / reference).

Returns:

Array of ratio values; NaN where y2 is zero or NaN.

Return type:

numpy.ndarray

fabplot.stats.metrics.calculate_smart_bins(data: ndarray) → int[source]¶

Calculate the optimal number of histogram bins for semiconductor data.

Uses the Freedman-Diaconis rule to avoid aliasing in continuous distributions.

Parameters:

data (numpy.ndarray) – 1D numpy array of numerical data.

Returns:

Recommended bin count, clamped between 10 and 200.

Return type:

int
